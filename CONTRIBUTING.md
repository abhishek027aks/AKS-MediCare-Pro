# Contributing to AKS MediCare Pro

Thank you for considering contributing.

We welcome bug fixes, improvements, documentation updates, feature suggestions, and code contributions.

---

# Getting Started

## Fork Repository

Click the **Fork** button.

Clone your fork:

```bash
git clone https://github.com/YOUR_USERNAME/AKS-MediCare-Pro.git
```

Move into project

```bash
cd AKS-MediCare-Pro
```

Install packages

```bash
flutter pub get
```

Run

```bash
flutter run -d windows
```

# Commit Messages

Use Conventional Commits.

Examples:

```
feat: add pharmacy module
fix: billing calculation
docs: update README
refactor: patient repository
style: improve dashboard UI
```

---

# Pull Request Checklist

Before opening a PR:

- flutter analyze passes
- flutter test passes
- No unnecessary files
- Documentation updated
- Screenshots included (if UI changes)

---

# Branch Naming

```
feature/login

feature/pharmacy

bugfix/billing

hotfix/dashboard

docs/readme
```

---

# Code Style

- Write reusable widgets.
- Keep methods small.
- Avoid duplicate code.
- Prefer composition.
- Use meaningful names.
